Web XMobile Project

Introduction

Web XMobile Project is an e-commerce website developed using PHP and MySQL. The system allows customers to browse products, manage shopping carts, place orders, and manage personal accounts.

Features

Customer

 Register and login
 View product details
 Search products
 Add products to cart
 Place orders
 Manage profile

Admin

 Manage products
 Manage categories
 Manage customers
 Manage orders
 View sales statistics

 Technologies Used

 PHP
 MySQL
 HTML5
 CSS3
 JavaScript
 Bootstrap
 XAMPP

 Installation

1. Clone the repository

```bash
git clone https://github.com/hoanglongdev-16/web-xmobile-project.git
```

2. Copy project to XAMPP htdocs folder

3. Import database into phpMyAdmin

4. Start Apache and MySQL

5. Open browser:

```text
http://localhost/web-xmobile-project
```
