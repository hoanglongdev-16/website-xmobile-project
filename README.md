XMobile - Mobile Phone E-Commerce Website

Overview

XMobile is an e-commerce website developed using PHP and MySQL. The system allows customers to browse products, search for mobile phones, manage shopping carts, place orders, and track purchase activities. Administrators can manage products, categories, customers, and orders through a dedicated administration panel.

This project was developed as a university web programming project to apply knowledge of database design, backend development, and frontend web technologies.

---

Features

Customer Functions

 User registration and login
 Browse products by category
 Search products by keyword
 View product details
 Add products to shopping cart
 Update and remove cart items
 Place orders
 Manage personal account information
 View order history

Administrator Functions

 Secure administrator login
 Product management (Add, Edit, Delete)
 Category management
 Customer management
 Order management
 Dashboard for system administration

Installation Guide

Requirements

 PHP 7.x or later
 MySQL
 XAMPP

Setup Steps

1. Clone the repository

```bash
git clone https://github.com/hoanglongdev-16/website-xmobile-project.git
```

2. Copy the project folder into:

```text
xampp/htdocs/
```

3. Create a database in phpMyAdmin.

4. Import the provided SQL file into MySQL.

5. Start Apache and MySQL from XAMPP Control Panel.

6. Open the website:

```text
http://localhost/Ban_DienThoai/Xmobile-master/customers/index.php
```
